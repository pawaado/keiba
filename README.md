# 競馬 期待値検証トラッカー

GitHub Pagesでそのまま使える静的Webアプリです。

## 使い方
1. `index.html` / `style.css` / `script.js` を同じリポジトリ直下に置く
2. GitHub Pagesを有効化
3. iPhone等のブラウザから開いて記録

## 重要
記録データはブラウザの localStorage に保存されます。
GitHub側には自動保存されないため、定期的に「JSONを書き出す」でバックアップしてください。

## 記録方針
買った馬券だけでなく、見送った候補も残し、レース後に結果と「公式払戻（100円あたり）」を入力すると、
EVしきい値を後から変えた仮想検証ができます。

## 主な分析
- 券種別の件数 / 的中率 / 回収率
- 予測EV帯別の回収率
- 予測確率の校正（予測20〜30% → 実際もその程度当たったか）
- EVしきい値別の100円均等購入シミュレーション

## CSV
CSVはExcel等で開けるようUTF-8 BOM付きで出力します。
